# threejs_film: storyboard, animatic and layout lock from the baked plan

The film is planned once (`tools/film_plan.py check film.json` writes `out/plan/camera_baked.json` and `performance_baked.json`). This kit only PLAYS that plan: toon sets, the vector2d puppets as flat cards, one-word captions. It owns no timing and no camera maths.

```
node render.mjs <film.json> --storyboard      # out/storyboard.html + .png: START and END panel per station, CAM / MOVE / WORD strip
node render.mjs <film.json> --animatic        # out/animatic.mp4 at half size (voice/voice.wav is muxed when it exists)
node render.mjs <film.json> --frames 0,45     # out/stills/f_#####.png
node render.mjs <film.json> --visibility      # out/plan/visibility.json: where every character and prop sits in frame, per frame
node render.mjs <film.json> --export-lock     # out/lock/: what the Blender look pass reads (below)
node render.mjs <film.json> --serve           # watch it play in a browser
```

Options: `--scale 0.5`, `--no-captions`, `--card-px 2`, `--puppets <dir-or-file,...>`. Needs node 18+, playwright with its Chromium (`npm install` then `npx playwright install chromium`, once, in the skill folder) and ffmpeg on the PATH. three.js r165 is in `vendor/`.

- **Files.** `film.js` + `film_page.html`: the player (`window.setup(cfg)`, `window.renderFrame(f)`). `render.mjs`: the command line. `puppets.mjs`: adapter to the character package (`stateKey`, `svgFor`). `poses.mjs`: pose library (hand targets, held props drawn at the hand). `sets/<name>.js`: one module per set.
- **Characters.** The package path is one value: `--puppets`, else env `PUPPET_PKG`, else film.json `"puppet_pkg"`, else the locked package `templates/vector2d_characters/code/` (the characters work owns it; this kit never edits it). It is copied to `out/.puppet_cache/` and never edited. Cast entry: `"puppet": "stationmaster"` (a name in cast.mjs) or `"form:<name>"` (a body form: kid, lady, elder, baby, ...), plus `"height"` in metres.
- **The cast (150 characters).** `"puppet": "cast:<name>"` plays any character from the cast sheets (`templates/vector2d_characters/code/sheets/sheetNN.mjs`; pictures in `sheets_png/`), or `"cast:sheet03/<name>"` when two sheets share a name (`queen` is on sheets 01, 03 and 14). The sheet gives the hat, hair, costume and held things; the film gives face, mouth, blink and pose. `"standard"` = the character's own face. With pose `stand` it keeps its own arms and props; a gesture pose redraws the arms, and a hand-held item then stays where the sheet drew it. Cast characters are drawn for the front view. Tested on `cast:pharaoh`, `cast:cowboy` and `cast:sheet03/queen` in the example film.
- **Sets.** `places.<name>.set` names `sets/<set>.js` (the episode's own `sets/` folder wins). It exports `build(THREE, scene, film, ctx)` and may return `{ update(f, t), anchors }`. Plan coordinates are metres, Z up; use `ctx.B2T([x, y, z])`. Give every mesh a `name` and `userData.role` (ground, wood, metal, cloth, glass, stone, brick, plaster, roof, water, foliage, lamp) or an exact `userData.mat = "wood_grain"`.
- **Poses.** Add a line to `POSES` in `poses.mjs`: a hand target `[out, down]` in arm lengths from the shoulder. An unknown pose warns and stands.
- **Lock format** (`out/lock/`, about 16 MB for the demo, 30 s to write):
  - `sets/<place>.glb`: the set only (no sky, lights, camera or cards), exported Y up as three.js has it. Blender's glTF importer turns glTF (x, y, z) into (x, -z, y), which is the plan's (x, y, z), so do not rotate it. Materials are named `mat:<library name>`, or `mat:<library name>.<rrggbb>` when a set uses one in several colours (read the name up to the first dot); untagged ones are `mat:untagged_<rrggbb>`. The colour is the base colour. Node extras carry `role`, `mat`, `color`. Moving set parts are in their frame 0 pose.
  - `cards/<who>/s0001.png ...`: one transparent drawing per unique drawn state, 1600 x 3000. `cards/<who>/index.json`: `{ who, puppet, px: [w, h], ground_px, centre_px, height_m, metres_per_px, images: [{ img, file, keys }], runs: [{ f0, f1, img, pos: [x, y, z], flip, visible }] }`. `img` is 1-based, `pos` is where the soles stand (plan coordinates), the image is centred on `pos` in x, and the card turns to the camera about the vertical axis only. `flip` is always false (the rig draws both facings). Runs split per frame while a character moves.
  - `lock.json`: `{ kit, lock_version, title, fps, frames, size, coords, places: [{ name, set, light, glb, meshes, materials, takes: [{ take, f0, f1 }] }], cards: [who], card_info: { who: { puppet, index, images, runs, height_m } }, sha1: { "camera_baked.json", "performance_baked.json" } }`. Re-export after every re-bake.
- **Placeholders, on purpose.** Moods are a colour wash and fx are a ring at the named prop: they show WHEN and WHERE, the look pass designs them. Unknown props are a lettered disc. Visibility is projection only (no occlusion). Set light is preview light.
- **Rig hooks still needed from the characters package.** Legs for a walk cycle; an arm layer in front of the head; shoulders and resting hands as data (now parsed from the arm path); hair exported apart from the face on forms; `stationmaster.props()` without its baked arm; blink and visemes on meme faces (a blink keeps the meme face today); side and back views of gestures.
